# RDQ 需求規格：學生與教師入口分流

## 一句話任務
將互動講義入口改為學生免密碼查看講義與教師密碼驗證管理的雙入口架構。

## ✅ 已確認
- 學生回家後可不輸入密碼查看上課 PDF 講義。（Ⅰ）
- 學生可直接使用現有分享網址進入，也可由入口網址查看公告與所有版面。（Ⅲ）
- 個別學生版面不顯示公告；公告只放在入口網站與教師版本。（Ⅰ）
- 入口網站另設教師入口，點擊後先開密碼輸入彈窗。（Ⅰ／Ⅲ）
- 教師密碼驗證成功後，同一工作階段可使用管理、編輯與課堂頁。（Ⅲ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 入口網站公開列出所有「啟用」版面，封存版面不列出；點擊版面後進入對應學生網址。
- 學生版面沿用目前可作答功能，只移除公告，不另做閱讀專用模式。
- 教師入口沿用現有 `AdminPassword`、教師 token 與自訂 Modal；直接開啟教師路由而未驗證時，也導向同一密碼彈窗。
- 學生公開網址的存取權限等同「持有網址即可查看」，不新增帳號、學生密碼或活動碼。

## ➕ 已採納（象限Ⅳ）
- 教師分享與 QR Code 功能只產生學生網址，不把管理網址交給學生；增加路由分流與回歸測試。

## ❌ 排除項（明確不做）
- 不在個別學生版面顯示公告卡片。
- 不新增學生登入、學生密碼、Google 帳號或活動碼。
- 本階段不新增教師登出按鈕與自訂逾時機制，沿用現有 token 行為。

## 📋 一段式需求規格
請在現有互動講義系統建立公開學生入口與密碼保護教師入口。根網址的入口網站不要求密碼，顯示公告與所有啟用中的教材版面，學生可點選版面進入對應的 `?board=...` 學生網址；既有分享網址也必須直接開啟學生版，讓學生回家後仍能查看上課 PDF 講義。個別學生版面不顯示公告，並沿用目前學生端功能。入口網站另設教師入口，點擊後以自訂 Modal 輸入現有 `AdminPassword`，驗證成功後在同一工作階段開放管理、編輯與課堂頁；未驗證直接開啟教師路由時，也必須先完成密碼驗證。教師分享與 QR Code 只產生學生網址，不產生教師管理網址。沿用原生 HTML、Vanilla JavaScript、GAS、IndexedDB 與現有自適應介面，不新增帳號系統或學生存取碼。

## ✔ 驗收條件
- [ ] 根網址可免密碼開啟入口網站，顯示公告與所有啟用中的版面。
- [ ] 直接開啟學生分享網址可免密碼查看 PDF，個別學生版面沒有公告。
- [ ] 教師入口先開密碼 Modal，驗證成功後可進入管理、編輯與課堂頁，錯誤密碼不得進入。
- [ ] 教師產生的分享網址與 QR Code 只指向學生版，學生無法由介面取得教師管理入口。
